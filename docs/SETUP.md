# Установка в Google Apps Script

Эта инструкция нужна для создания своей рабочей копии. Если приложение уже работает в твоём Google-аккаунте, публикация исходников на GitHub не требует повторной установки. Для изменений существующей копии смотри раздел «Обновление» ниже.

## Первая установка

1. **Создай проект.** Открой [Google Apps Script](https://script.google.com), нажми «Новый проект» и назови его `eCalculator`.

2. **Подготовь исходники в редакторе.** Оставь существующий `Code.gs`, а остальные файлы создай через «+» рядом с надписью «Файлы». Один раз перенеси содержимое файлов репозитория по таблице ниже. Для нового файла вводи имя без расширения — редактор допишет его сам.

   | Из репозитория | Тип в меню «+» | Имя в редакторе |
   | --- | --- | --- |
   | `Code.gs` | Уже создан | `Code` — замени стандартный пример |
   | `ESchool.gs` | Скрипт | `ESchool` |
   | `Extensions.gs` | Скрипт | `Extensions` |
   | `Index.html` | HTML | `Index` |
   | `Core.html` | HTML | `Core` |
   | `Schedule.html` | HTML | `Schedule` |
   | `ESchoolUI.html` | HTML | `ESchoolUI` |

   Открывай файлы на GitHub через кнопку **Raw**, чтобы копировать только код. `Icon.png`, `README.md`, `docs`, `assets`, `tests` и `package.json` в редактор Google переносить не нужно.

3. **Настрой манифест.** Открой шестерёнку слева → включи показ файла `appsscript.json` → вернись в редактор. Замени содержимое появившегося манифеста содержимым `appsscript.json` из репозитория.

4. **Сохрани проект.** Нажми значок сохранения и дождись надписи «Сохранено на Диске».

5. **Создай таблицу приложения.** Открой `Code.gs`, в списке функций сверху выбери `setup` и нажми «Выполнить». Подтверди запрос Google на доступ к таблицам и внешним запросам. При успешном завершении в журнале выполнения появится ссылка на созданную таблицу. Вручную создавать таблицу и вписывать её ID в код не нужно.

6. **Опубликуй веб-приложение.** Нажми «Начать развертывание» → «Новое развертывание». В выборе типа укажи «Веб-приложение», запуск — **«От моего имени»**, доступ — **«Только у меня»**. Нажми кнопку развёртывания.

7. **Открой рабочую ссылку.** В результате публикации скопируй URL веб-приложения с окончанием `/exec` и открой его под тем же Google-аккаунтом. Ссылку библиотеки и адрес редактора для запуска использовать не нужно.

8. **Подключи школьный дневник.** В приложении перейди в «Настройки → eSchool» и войди в свой аккаунт ученика. Дождись завершения обновления. Если eSchool не нужен, предметы и оценки можно вести вручную.

9. **Проверь сохранение.** В разделе «Оценки» создай пробный предмет и добавь оценку. После статуса «Всё сохранено» перезагрузи страницу. Если запись осталась, подключение таблицы работает.

## Обновление существующего приложения

1. **Обнови код.** В своём прежнем проекте Apps Script замени содержимое изменённых исходников актуальным кодом из репозитория. Сохрани проект. Свойство `STORAGE_ID` и таблицу «Журнал» оставь как есть — они связывают приложение с твоими записями.

2. **Выбери новую версию.** Открой «Начать развертывание → Управление развертываниями», выбери активное приложение, нажми карандаш и в поле «Версия» укажи «Новая версия».

3. **Примени обновление.** Нажми «Начать развертывание», дождись завершения и перезагрузи прежний адрес `/exec`. Ссылка и накопленные данные сохранятся.

Изменение файлов на GitHub само по себе не обновляет Apps Script.

## Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| «Сначала запустите функцию setup» | Выполни `setup` в редакторе Google и обнови страницу приложения |
| «Нет связи» | Проверь интернет и вход в нужный Google-аккаунт; нажми «Повторить» |
| Ошибка запуска или старый интерфейс | Проверь имена всех семи исходников, затем опубликуй новую версию |
| Нет оценок eSchool | Проверь подключение в настройках и нажми «Обновить всё сейчас» |

Справка Google: [веб-приложения](https://developers.google.com/apps-script/guides/web), [свойства проекта](https://developers.google.com/apps-script/guides/properties).
